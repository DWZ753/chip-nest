# ChipNest v1.2.2 · 合并格模式

修正 v1.2.1 里两处别扭的设计：元件窗口不再管位置，多格共用改在主页面用「合并格」模式点出来。

## 本版改动

### 元件窗口瘦身

- **去掉「位置」与「选格」**：新建时点哪一格就是在哪一格，搬家走主页面的「移动」模式，
  窗口里不再重复问一遍位置；
- **去掉「占用格子」那一块**：不再用下拉选格子（那正是要避免的"猜编号"）；
- 修掉新建窗口出现**两个「初始库存」**的问题，现在只剩一个（与补货阈值并排）。

### 新增「合并格」模式（主页面右上角）

- 点「合并格」进入：先点一个**有料**的格子作为主格（卡片高亮，顶部显示「主格「××」共 N 格」）；
- 再点任意**空格**：并进来，成为该物料的共用格（库存不变，仍然只有一个总数）；
- 点那一格的**共用卡**：解除（该格恢复成空位）；
- 换主格就点另一个有料格子；按 Esc 取消主格、再按一次退出模式，或点「退出合并」；
- 合并模式下网格自动按"分开显示"呈现，每一格都能单独点，不会被跨格大卡挡住；
- 操作结果即时提示（已把 1区/1层/1格 并入「××」／已解除 1区/1层/1格）。

### 其它保持

- 补货阈值仍然只看初次入库数量（100 → 20、5 → 2，可手动改，已有元件不受影响）；
- 「选格」按钮只保留在真正需要选位置的地方：**BOM 整表入库**与**手工入库**的每一行。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.2.2.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.2.2**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢。
