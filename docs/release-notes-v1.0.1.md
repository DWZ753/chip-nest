# ChipNest v1.0.1 · 应用图标版

本版为 v1.0.0 之后的补丁版本，主要内容是**补齐应用图标**，功能与 v1.0.0 一致。

## 本版更新

- **应用图标**：安装包、开始菜单/桌面快捷方式、窗口与任务栏统一使用 ChipNest 图标（多尺寸 ico，含 256px）；
- **网页图标**：内置 favicon.ico / 192px / 512px，浏览器与 PWA 场景可直接使用；
- **README**：顶部加入应用图标；版本说明更新为 v1.0.1；
- 前端、后端功能无改动；数据库结构无变化，升级安装数据不丢。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.0.1.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.0.1**（图标同步更新到快捷方式）；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢失。

## 说明

- 若桌面/开始菜单仍显示旧图标，属于 Windows 图标缓存，重登录或刷新图标缓存即可；
- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择“更多信息 → 仍要运行”；
- 源码与反馈：https://github.com/DWZ753/chip-nest
