# v1.9.0 本地库存工作流更新

新增功能与两张数据表，按语义化版本升次版本。

## 新增

- 自动备份：开关、小时周期、自动备份保留数量和自定义目录。
- 备份历史：查看、下载、删除、恢复；原生文件夹选择器。
- 库存盘点：实盘输入、差异核对、整体校正与整体撤销。
- BOM 项目：保存清单、人工匹配、制作份数、取料进度和制作副本。
- 补货清单：汇总多项目剩余需求与库存阈值，导出 CSV。
- 重复元件核对：字段对照、组选择、料号冲突跳过和过期预览校验。

## 行为

- 取料与项目进度同时写入，重复请求不会重复扣库存。
- 可以先取足料部分，补料后重新规划剩余行；已取步骤继续保留。
- 撤销项目取料会同时回退对应进度。
- 盘点期间账面数量变化时整批取消，避免覆盖新库存。
- 合并空料号由同组非空料号补齐；阈值与卡片显示配置保留主格设置。
- 自动备份只在软件运行时执行，每分钟检查一次。
- 保留策略只清理自动备份；手动及清空、恢复前备份仍保留。
- JSON 备份增加项目数据，旧 JSON 备份仍能恢复。
- 老数据库启动时自动创建新表，不改库存字段或位置。

## 菜单

- 「库存」增加「盘点」「补货清单」，BOM 项目位于「BOM 取料」。
- 「设置 → 备份与恢复」提供备份策略与历史。
- 联网同步留待下一轮，本版本不需要部署服务器。
