# ChipNest v1.5.0 · 搜索改进

## 本次改动

- 搜索结果显示命中元件数量；上一个、下一个按钮按仓库位置逐项定位，同一元件的多个格子只计一次。搜索框中可用回车、Shift+回车切换。
- 网格搜索只传输命中 ID；开启大小写、全字或正则选项时由数据库筛选，元件列表接口在筛选后分页，减少对象加载与传输。

## 升级

安装前关闭正在运行的 `ChipNest.exe`。数据保存在 `%APPDATA%\ChipNest\`，此版本没有数据库结构变更。
