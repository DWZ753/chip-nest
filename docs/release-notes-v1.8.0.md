# ChipNest v1.8.0 · 主格定位与菜单整理

## 新增

- 副格卡片和编辑窗口显示主格位置，支持定位并短暂高亮主格。
- 主格搬家或由剩余格子接替后，副格显示的位置随之更新。
- 跨区、跨层及整块合并显示的副格均可追踪主格。

## 菜单调整

- 「库存」分为入库、BOM 取料、元件整理、操作记录。
- 手工入库和 BOM 整表入库集中在「入库」，手工入库关闭后返回库存。
- 合并重复元件从设置移到「库存 → 元件整理」。
- 批量清除供应商料号从网格多选移到「元件整理」，按元件勾选清理。
- 最近操作与撤销从仓库布局移到「库存 → 操作记录」。
- 「仓库布局」集中管理区名称、层数及行列尺寸。
- 「设置」分为外观、硬件、备份与恢复、数据清理、关于。
- 主页面保留移动、合并格、停用格和多选。

## 修复

- 离开元件整理或关闭库存后清空合并结果与预览，再次打开不残留旧提示。

## 升级与验证

本版本为候选安装包，等待本地验证后发布。
安装前关闭正在运行的 `ChipNest.exe`。数据仍保存在
`%APPDATA%\ChipNest\`，没有数据库结构变更。

1. 从副格定位主格，检查跨区合并后的主格位置。
2. 检查库存的四个分组，以及手工入库关闭后返回库存。
3. 合并后离开元件整理，再次进入时确认旧提示已消失。
4. 在操作记录中检查撤销，在设置中检查备份与恢复入口。
