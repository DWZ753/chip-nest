# ChipNest v1.0.0 · 智能元件管家 正式版

数字孪生元件管理工具：用卡片网格管理元件仓库，支持模糊搜索、BOM 导入与按灯带顺序的引导取料，
可接 ESP32 + NeoPixel 灯带做槽位指示。Windows 安装包即装即用，**无需 Python**。

## 本次亮点

- **元件仓库**：分区/层/格网格，每个区可独立设置行列尺寸；卡片名称两行显示，底部色带显示库存状态（充足/偏低/告急/零库存脉冲）。
- **字段与标签统一为一条显示链**：标称值、封装、厂商料号、供应商料号、自定义标签可以混排、逐个开关是否显示、拖动调整顺序；
  格子按可用宽度自适应排布，放不下自动折叠为 `+N`。
- **标签双状态编辑**：状态 1 点按切换是否显示在格子上；状态 2 专门拖动排序（此时隐藏删除键，避免误操作）。
- **BOM 导入与取料**：支持粘贴文本与 `.xlsx`（自动识别名称/封装/数量/料号表头）；解析预览 → 库存匹配规划 →
  缺货清单 → 按灯带顺序逐格引导，每步自动原子出库并记入操作流水。
- **手工入库**：先逐行填好物料信息再选空格批量建档。
- **批量操作**：多选（支持整区选择/全选）批量删除、批量清除工程专用的供应商料号（有料号的格子会高亮显示）。
- **硬件联动**：ESP32 串口 PING/PONG 握手，库存不足红灯、引导高亮；无硬件时自动进入模拟模式，功能完整可体验。
- **界面**：深色科技风（可切浅色），字号可整体缩放；下拉选择、数字步进、标签编辑均为自绘控件。
- **数据安全**：升级安装保留数据；老版本数据库启动时自动增量升级（无需删库）。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.0.0.exe`；
2. **升级前请先在任务管理器结束 `ChipNest.exe`**（避免旧实例占用文件）；
3. 运行安装包按向导安装，完成后启动，左上角应显示 **v1.0.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢失。

## 系统要求

- Windows 10 / 11（64 位）
- 可选硬件：ESP32 开发板 + NeoPixel 灯带（固件见仓库 `hardware/chipnest_led_server/`）

## 说明

- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择“更多信息 → 仍要运行”即可；
- 各厂商料号/供应商料号仅存本地数据库，不会上传；
