# v1.9.1 联网识别规格匹配修复

本版本修复识别逻辑，不改变接口或数据库结构，按语义化版本升修订号。

## 原因

- 上游通用搜索对短关键词返回宽泛结果；原程序只要收到候选就停止
  查找，没有核对候选类别和数值后再决定是否换数据源。
- 阻值与容值类型不同时，原比较函数返回“无法判断”，电容因此
  没有从电阻查询中排除；封装相符、常备料和库存热度仍会加分。
- 原程序没有解析额定电压与安装方式，“贴片”只是传给上游的关键词。
  上游部分直插电容的贴片标记也有误，需结合封装、描述和参数核对。
- 分类接口需要传基础单位数值；实测 `resistance=1k` 被当作 1Ω，
  修复后传 `resistance=1000`。容量同样转换为法拉后查询。

## 修复

- `1k 0603` 按阻值和封装查找电阻，不再混入电容。
- `470uF 25V 贴片` 同时核对容量、电压和安装方式，不再推荐直插件。
- 支持大小写、µ/μ/u、4k7/4R7 等常用数值写法和查询字段顺序变化。
- 支持贴片、直插、插件、SMD/SMT、THT/through-hole 安装方式。
- 先核对明确规格，再按常备料、库存等条件排序；没有符合规格的
  候选时返回空结果，不自动填入其他规格。
- 所有后备数据源与详情补全使用同样的规格校验。
- 容量不再误取参数表中的等效串联电阻；不会复用旧的错误搜索缓存。

## 验证

- 后端完整测试 159 项通过。
- 前端类型检查、构建及桌面入口语法检查通过。
- 独立数据库业务冒烟通过，正式库存未操作。
- 打包版独立目录冒烟通过：三个接口 200，版本 1.9.1，界面标记
  与原生目录选择桥接存在，退出码 0。
- 真实联网查询 `1k 0603` 返回 8 个符合规格的电阻候选；
  `470uF 25V 贴片` 返回 6 个符合容量、电压与安装方式的电容候选。
- 详情接口本轮返回 403 时，保留搜索数据源中已核对的候选。
