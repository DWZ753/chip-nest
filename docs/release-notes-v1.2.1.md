# ChipNest v1.2.1 · 阈值联动与选格方式

修补 v1.2.0 里几处不上手的地方：阈值改成最朴素的自适应、数字框能看能点、
格子显示单独成栏、所有"选哪一格"的地方改成回主页面点空格。

## 本版改动

### 补货阈值：只看入库数量

- 新建元件时，初始库存填好后阈值按 20% 自动跟着走：入库 **100 → 阈值 20**、**5 → 2**、12 → 2；
- 之后再改初始库存，阈值按新数量重算一次（改一次、跟一次）；
- 阈值随时可以手动改，改完就按你填的来；
- **只对新建元件生效**：已经建好的元件改库存不会动它的阈值。

### 数字调节框

- 加减框里的数字改为居中并占满剩余宽度（之前数字被挤在很小的框里）；
- 补货阈值与初始库存并排一行，各占一半宽度，点起来更顺手。

### 设置分组

- 「外观」改名 **主题**（浅色/深色）；
- 新增 **格子显示** 一栏：「同一物料的相邻占用格」→ 「合并一张卡」／「分开显示」，
  当前生效的那个会高亮，不会再和主题混在一起看不清状态。

### 选格：回到主页面点空格

- 元件窗口的「区/层/格」三个下拉全部去掉，改成一行**位置**显示（如 `1区/1层/2格`）+「选格」按钮；
- 点「选格」后窗口自动让开，回主页面点一个空格就选中，完成后窗口自动回来；按 Esc 取消；
- 点到的格子已经有料时给一句提示（该格已被占用），不会误选；
- 同样用在 **BOM 整表入库** 与 **手工入库** 的每一行「选格」上，不用再猜格子编号。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.2.1.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.2.1**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢。

## 说明

- 「合并一张卡」只在**同一层、同一行、且位置连续**的占用格之间生效；跨行或跨层的占用格
  仍显示成指向主格的共用卡；
- 每区的层/行/列仍是数字输入，它们是尺寸不是位置。
