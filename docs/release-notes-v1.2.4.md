# ChipNest v1.2.4 · 显示链与文案

三处细节：展示标签能多挑几个、跨格卡的显示链按实际大小铺、入出库按钮去掉加减号。

## 本版改动

### 展示标签最多 6 个

- 「展示标签」（直接画在格子上的标签）上限从 3 个放宽到 **6 个**，标签编辑器里点选即可（后端 schema 同步）；
- 加上 4 个字段，跨格大卡最多能摆 10 个 chip。

### 显示链按卡片实际大小铺

- 以前显示链**写死最多两行**，放不下就折成 `+N`；现在行数按卡片实际尺寸算：
  普通格子维持两行不变，跨格卡（宽卡靠宽度、高卡靠高度）能铺几行就铺几行；
- 卡片尺寸变化（跨度改了、布局改了）会重新计算，不会停在旧结果上。

### 文案

- 入出库按钮去掉 **＋／－**，直接写「入库」「出库」（加减号容易让人以为是加减某个数）；
- 设置里的「卡片」一栏改为 **合并渲染 / 分开渲染**（原来的「合并一张卡 / 分开显示」）。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.2.4.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.2.4**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢。
