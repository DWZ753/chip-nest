# ChipNest v1.1.0 · 一键清空数据

本版新增「一键清空所有数据」：不用手动一格一格删，直接回到刚装好的干净状态。
其余功能与 v1.0.1 一致。

## 本版更新

- **一键清空**：设置 → 数据 →「清空所有数据」，手输「清空」两个字确认后执行；
  删除全部元件与操作流水，可勾选同时把仓库布局恢复为 1 区 × 3 层 × 1 行 4 列；
- **按钮会看情况变灰**：库里既没有元件也没有流水时，清空按钮不可点，并提示「当前没有元件与操作流水」；
  确认框里的删除数量取自后端实际计数，跟当前搜索筛选无关；
- **清空前自动备份**：把现有数据整份导出成 JSON（元件、标签、卡面显示顺序、布局、操作流水），
  存到数据目录的 `backups\` 下，文件名带清空时间，需要时可据此手工找回；
- **清空后的界面**：自动收起正在进行的 BOM/引导弹窗、清空搜索框、网格整体刷新；
  灯带上还亮着的灯位一并熄灭；
- 数据库结构无变化，升级安装数据不丢。

## 使用步骤

1. 打开顶栏「设置」，滚到最下方「数据」一栏；
2. 点「清空所有数据」→ 在确认框里输入「清空」两个字（确认按钮才会亮）→ 点「确认清空」；
3. 清空完成会显示删掉的元件/流水条数与备份文件路径。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.1.0.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.1.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢失；备份在同目录 `backups\` 下。

## 说明

- 清空不可撤销，所以强制手输确认词；但清空前一定会先留下备份文件（备份写不成功就中止清空）；
- 只想清内容、保留现在的分区与区名：确认框里把「同时把仓库布局恢复为…」的勾去掉；
- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择"更多信息 → 仍要运行"。
