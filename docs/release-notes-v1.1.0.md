# ChipNest v1.1.0 · 里程碑版

从 v1.0.1 之后的功能合并成这一个版本发布。包含：搬家方式、每区独立层数、联网识别、
灯带序号重排、BOM 整表识别料号、一键清空数据。数据库升级会自动补列补表，老数据不丢。

## 新功能

### 搬家：点按拿起 / 放下

- 右上角「移动」按钮：点一下进入移动模式，点一个格子拿起（卡片高亮），再点虚线空格放下；
- 拿起来后按 Esc 或再点它自己 = 放回原处；「退出移动」或 Esc 结束模式；
- 只能放到空格；搬完提示「已把『××』从 1区/1层/0格 搬到 1区/1层/1格」，操作流水同步留一条；
- 多选模式下点格子仍是选中，不会误搬。

### 每个区可以单独设层数

- 「仓库布局」里每个区各有 **层 / 行 / 列** 三个输入框，新建区沿用上面的默认值；
- 网格渲染、位置校验、编辑窗口的层下拉、BOM 与手工入库的空位分配、游离元件判断都按本区层数走；
- 老库升级后每区沿用原来的全局层数。

### 联网识别（自动填字段）

- 元件窗口最上方「联网识别」：输入 `10k 0603`、`100nF 0402`、`C14663`、`STM32H750VBT6` 等，回车或点「识别」；
- 自动判断编号还是关键词：编号走立创详情（参数最全），关键词走 jlcsearch 搜索，
  按匹配度排序后再用立创详情补参数与数据手册；型号查不到时自动转 EasyEDA 精确检索；
- 排序会核对标称值（搜 10k 不会再推荐 510k 的料），并优先立创基础库/优选库的常备料；
- 自动填：名称（如 `10kΩ 0603 贴片电阻`）、标称值、封装、厂商料号、供应商编号（=立创编号），
  同时显示关键参数与数据手册链接；候选可点选替换，选中的那条会高亮打勾；
- 数据源：jlcsearch（免鉴权）为主，立创详情补齐，EasyEDA 兜底；结果本地缓存
  （搜索 12 小时、详情 7 天），同一料号不重复打网络；断网时只提示，不影响手工填写。

### BOM 整表入库可以自动识别料号

- 「BOM 导入 → 整表入库」里新增「识别料号」按钮，对还没有编号的行逐条联网识别，
  自动补上厂商料号与立创编号（已有编号的行跳过），带 N/M 进度与「停止」；
- 每行右侧也能单独识别一条。

### 灯带序号重排

- 设置 →「灯带序号 → 按位置重排」：按 区→层→格 把灯带序号重排一遍，
  老版本自动分配灯号有 bug（多个格子共用一颗灯，引导时点错格），点一下即可对齐；
- 重排会写一条操作流水，没变动时不写。

### 一键清空数据

- 设置 →「数据 → 清空所有数据」：手输「清空」两个字确认后，删除全部元件与操作流水，
  可勾选同时把布局恢复为 1 区 × 3 层 × 1 行 4 列；
- 清空前自动把现有数据整份导出成 JSON（元件/标签/卡面顺序/布局/流水）到数据目录的 `backups\`，
  备份写不成功就中止清空；库里没有可清内容时按钮是灰的。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.1.0.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.1.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢（数据库会自动补新列与新表）。

## 说明

- 联网识别与「识别料号」需要能访问外网（jlcsearch / 立创 / EasyEDA）；内网或断网只影响识别；
- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择"更多信息 → 仍要运行"。
