# ChipNest v1.7.0 · 手动备份与 BOM 匹配优化

## 新增

- 「设置 → 数据」支持创建备份，并下载可用于现有恢复功能的 JSON 文件。
- 备份包括元件与库存、附加格、布局、停用格和操作流水。
- 创建备份会保存到备份目录，并记录备份操作流水。
- BOM 匹配增加待确认候选，支持手动选择后重新规划取料。
- 主页面「合并格」支持手动合并两张相同的已有元件卡片。
- 保留先选中的主格，库存数量相加，转移另一元件的全部格子，支持撤销。

## 优化

- 统一大小写、全角字符、常见封装及阻容感单位写法。
- 库存名称和标签参与匹配，支持从描述中读取标称值。
- 近似名称、信息不足及歧义结果显示最多 5 个候选。
- 规格冲突不自动匹配；精确料号命中但规格冲突时显示待确认状态。

## 修复

- 修复 BOM 类别识别正则缺少括号导致的 Internal Server Error。
- 表格按列读取字段，保留 7805、AMS1117-3.3 等完整型号。
- 数量以数量列为准，型号中的 x6 等字符不再影响导入数量。
- 无效数量返回中文错误提示。
- 修复带附加格的元件合并时出现 Internal Server Error。
- 合并后标签可正常搜索，撤销可恢复原数量和附加格。
- 修复删除一个共用格时误删整组元件的问题，编辑窗口改为「删除此格」。
- 多选改为逐格选择和删除；删除主格时由剩余格子接替，库存数量不变。
- 仅删除最后一个存放格时移除元件，逐格删除支持撤销。

## 升级

安装前关闭正在运行的 `ChipNest.exe`。数据仍保存在
`%APPDATA%\ChipNest\`，本次没有数据库结构变更。
新增备份功能及接口，因此次版本号升至 1.7.0。
