# ChipNest v1.4.0 · 搜索、BOM 与数据恢复

## 本版更新

- 搜索框新增区分大小写、全字匹配、正则表达式三个开关，支持组合使用；全字模式搜 `47` 不再命中 `470`。无效正则会提示错误。
- 搜索时停用格也会变暗，清空搜索后恢复。
- BOM 支持读取 CSV 中的厂商与供应商料号，并优先按料号匹配库存；元件列表支持分页加载。
- BOM 引导时同步点亮对应硬件灯位，结束引导后恢复库存灯态。
- 设置中可选择 JSON 备份恢复数据，覆盖前会先备份现有数据。

## 安装与验证

1. 关闭正在运行的 `ChipNest.exe`。
2. 运行 `ChipNest-Setup-1.4.0.exe`，按向导完成安装。
3. 启动后检查左上角版本为 v1.4.0，并用 `47` / `470` 验证全字匹配。

数据仍保存在 `%APPDATA%\ChipNest\`。
