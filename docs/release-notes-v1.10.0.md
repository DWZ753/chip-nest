# v1.10.0 连续交互与卡片拖放

本版本新增连续交互、卡片拖放和兼容的移动接口，按语义化版本升次版本。

## 连续交互

- 设置、库存及入库子页面采用可中断的弹簧过渡、正文裁切推移和
  动态高度，减少切换时的位置突变、正文叠字与动画等待。
- 标签切换保留已访问页面的草稿；当前页面在动画过程中即可操作。
- 补齐联网候选高亮、变化字段、参数区域及仓库新建区的过渡。
- 输入框保留单一真实控件，手动编辑立即接管。

## 卡片与工具栏

- 卡片支持跟手拖放、空位放置、两卡交换与共用格移动。
- 支持边缘滚动、取消回弹；点击与键盘放置共用落位动画。
- 移动、合并、停用、多选采用互斥状态，统一清理临时选择。
- 四项操作使用单一顶部固定工具栏，入口原位转换为操作控件，
  按内容平滑调整宽度，退出后还原；移除底部重复操作框。

## 接口与数据

- 新增 `PATCH /api/v1/components/{id}/slots`，原子移动共用格。
- 移动记录审计流水，支持单步撤销，库存数量保持不变。
- 数据库结构与 Electron 主进程未修改，原有接口继续兼容。

## 范围与演示

- 当前范围尚未覆盖应用所有交互控件，后续以实际使用反馈继续调整。
- 现有 README 截图与演示来自旧版，尚未展示本版本全部交互。

设计与接手约定见 [连续交互重构交接](interaction_motion.md)。
