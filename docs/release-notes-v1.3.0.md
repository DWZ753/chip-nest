# ChipNest v1.3.0 · 移动模式、每区层数、联网识别

本版三件事：搬家改成「点按拿起/放下」、每个区可以单独设层数、新增联网识别自动填字段。

## 本版更新

### 1. 搬家改成移动模式（不再用拖动）

- 右上角新增「移动」按钮（和多选并排）：点一下进入移动模式，按钮变蓝、顶部出现提示条；
- 点任意格子把它拿起来（卡片高亮描边），再点任意虚线空格放下；空位会提前提示「放这里」；
- 拿起来后按 Esc、或再点它自己 = 放回原处；点「退出移动」或按 Esc 结束模式；
- 只能放到空格，已占用的格子不接受；搬完提示「已把『××』从 1区/1层/0格 搬到 1区/1层/1格」，
  操作流水同步留一条（从哪到哪、什么时候都查得到）；
- 多选模式下点格子仍是选中，不会误搬。

### 2. 每个区单独设层数

- 「仓库布局」里每个区都有独立的**层 / 行 / 列**三个输入框（此前层数是全局共用），
  新建区沿用上面的「默认层数 / 默认行数 / 默认列数」；
- 网格渲染、位置校验、编辑窗口的层下拉、BOM 与手工入库的空位分配、游离元件判断，
  全部按「该区的层数」走；
- 老库升级后每区层数默认沿用原来的全局层数，数据不受影响。

### 3. 联网识别（自动填字段）

- 元件窗口最上方新增「联网识别」：输入 `10k 0603`、`100nF 0603`、`C14663`、`STM32F103C8T6` 等，
  回车或点「识别」即可；
- 先判断是立创编号还是关键词：编号走立创详情（参数最全）；关键词先按品类（电阻/电容/单片机/稳压器）
  打分类接口，再按匹配度排序，最后用详情补齐参数与数据手册；
- 自动填好：名称（如 `10kΩ 0603 贴片电阻`）、标称值、封装、厂商料号、供应商编号（=立创编号），
  同时显示关键参数（阻值/精度/耐压…）与数据手册链接；多个候选可以点选替换；
- 数据源：jlcsearch（免鉴权）为主，立创详情接口补齐，EasyEDA Pro 兜底；结果落本地缓存
  （搜索 12 小时、详情 7 天），同一料号不会反复打网络；
- 断网或查不到时窗口里给出中文提示，不影响手工填写；识别只读取网络资料，不动你的库存和布局。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.3.0.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.3.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢（数据库会自动补新列与新表）。

## 说明

- 联网识别需要能访问外网（jlcsearch / 立创 / EasyEDA）；内网或断网时只影响识别，其它功能照常；
- 识别结果只是填进表单，保存前你仍然可以随便改；
- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择"更多信息 → 仍要运行"。
