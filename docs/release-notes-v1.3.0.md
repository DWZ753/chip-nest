# ChipNest v1.3.0 · 撤销、停用格、检索变暗

本版把"手滑"和"物理现实"两件事照顾上了：能撤销上一步、能标记坏掉的格子、检索不再让格子凭空消失；
顺带修掉联网识别点别的候选看不到参数的 bug。

## 新功能

### 撤销上一步（仓库布局 → 最近操作）

- 「最近操作」标题右侧新增「撤销上一步」，下面一行会写明**将要撤销什么**（如「将撤销：修改 贴片电阻：搬到 1区/2层/0格」）；
- 可撤销：建档、删除、搬家、互换、改名称/值/封装/标签、入出库、加/减占用格、合并重复元件；
- 实现方式是**改动前留快照**（位置 + 全部字段 + 占用格），撤销时整体还原 —— 不管一步里改了多少东西都能回到原样；
- 还原时若原位已被占用（或已标记不可用），会自动落到第一个空格并在结果里说明；
- 撤销栈留最近 30 步，落在数据库里，**关掉软件再打开也能撤**。

### 停用格（右上角「停用格」模式）

- 点一下进入，点任意**空格**即标记为不可用（斜纹格 + 禁用图标），再点它即恢复；
- 不可用格**不能放元件**（建档、搬家、当占用格都会被拒，提示「该格已标记不可用」）；
- 它也不算空位：BOM 整表入库、手工入库、合并格、自动搬入空格都不会往里放东西；
- 「清空数据」会把不可用标记一起清掉。

### 检索不再让格子消失

- 以前检索是"只显示命中的元件"，没命中的格子会变空 —— 于是在本来有东西的地方能点出「新建元件」；
- 现在检索**永远保留所有卡片**，命中的呼吸高亮，没命中的变暗（悬停可看清）；点变暗的卡片打开的是编辑，不会新建。

### 联网识别：点哪条候选都能看到参数

- 之前只有排第一的候选带参数与数据手册，点其它候选是空的；
- 现在每条候选都带参数：立创详情有该料时用详情（参数最全），没有时从描述里解析出精度/功率/额定电压/
  温度系数/工作温度/电阻类型等；点选候选取不到详情时会按编号再补拉一次（界面显示「查询中…」）；
- 数据手册链接取决于立创是否收录该料，没有就是没有。

### 其它

- 新增 `scripts/backup_data.py`：用 SQLite 快照（含 WAL 未落盘部分）备份数据库并导出 JSON，
  可随时手工跑一次。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.3.0.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.3.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢（会自动补新表）。
