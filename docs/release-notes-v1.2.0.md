# ChipNest v1.2.0 · 格位操作与多格存放

本版把"货架格位"这层做扎实了：格子能搬、能互换；一个物料可以登记多个格子（拆开存放）；
库里历史遗留的重复元件可以一键合并；补货阈值改成会跟着入库量走，但仍随时可手改。

## 新功能

### 搬家与互换（同一个「移动」模式）

- 点右上角「移动」→ 点一个格子拿起：
  - 点**虚线空格** = 搬到那里；
  - 点**另一个有料的格子** = 两个格子内容互换（位置和灯带序号一起对调，灯带仍一格对一灯）。
- 按 Esc 或再点自己 = 放回原处；两者都会在上方提示结果并写入操作流水。

### 一个物料占多个格子（拆开存放）

- 元件窗口新增「占用格子」：下拉挑一个空格子加进来，chip 上的 × 解除；
- 库存仍然只有一个总数，检索/BOM/取料都只出一条，不会因为拆开而算重；
- 主格卡片右上角带「N 格」角标；其它格子显示成指向主格的**共用卡**；
- 同一层里相邻的占用格默认合成一张**跨格大卡**（设置 →「跨格显示」可关，关掉就是共用卡形态）；
- 占用格同样参与"超出网格"提示与「自动搬入空格」，布局缩容不会把登记弄丢。

### 合并重复元件

- 设置 →「重复元件 → 合并重复元件」：扫描「同名 + 同标称值 + 同封装」的多条记录，
  先给预览（几条、合计多少），确认后合并：数量相加、标签取并集，
  其余记录的格子全部变成保留那条的占用格（所以合并完通常就是"一个物料多格存放"）。

### 补货阈值跟着入库量走

- 新建元件时阈值按入库量的 20% 自动给建议值（入库 100 → 阈值 20，最少 1，入库 0 用默认 5）；
- 阈值旁有「自动／手动」开关：自动时入库量改一次、阈值同步一次；
  手动改阈值会自动切到手动，再点回自动会立刻同步一次 —— 两边不会互相覆盖；
- 阈值输入改回 **＋/－ 步进框**；BOM 整表入库与手工入库的阈值也按各自数量推导。

### 其它

- 元件窗口的联网识别：输入框与「识别」按钮改成一行排布（按钮文字不再竖排）；
- 界面按规约清掉了说明性/注解文字，只留数据、状态与动作结果。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.2.0.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.2.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢（数据库会自动补新表/新列）。

## 说明

- 占用格只是"同一物料还放在哪几格"，不单独记数量；如果以后需要每格各记数量，说一声再加；
- 联网识别需要外网（jlcsearch / 立创 / EasyEDA），断网只影响识别；
- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择"更多信息 → 仍要运行"。
