# ChipNest v1.2.0 · 拖动搬家

本版新增「拖动格子搬到空格」，并修掉一个灯带序号重复的老问题。

## 本版更新

- **拖动搬家**：按住任意格子拖到虚线空位，松手即搬。拖动过程中源头卡片变半透明、
  所有空位轻微提示可放、指针所在那一格高亮，顶部显示「正在搬『元件名』」；按 Esc 放弃。
  多选模式下不触发拖动（那时的点击是选中），不会误拖。
- **搬完有反馈**：上方弹一条「已把『××』从 1区/1层/0格 搬到 1区/1层/1格」，
  同一动作写入操作流水（搬到哪个位置、什么时间，都能查到）；只能放到空格，已占用的格子不接受。
- **修复灯带序号重复**：自动分配灯序号以前取的是「第一行的值」，从第 3 个元件起就会和前面的撞号，
  多个格子共用一颗灯（引导取料时会点错格）。现在改为按现有最大值 +1 分配。
- 数据库结构无变化，升级安装数据不丢。

## 需要留意

- 老库里**已经存在**的重复灯序号不会被升级过程改动（不擅自改历史数据）。
  如果需要按「区 → 层 → 格」的顺序把灯序号重排一遍，说一声，我加一个一次性的整理按钮。

## 使用步骤

1. 按住任意格子不放，拖动鼠标：能放的空位会出现虚线高亮；
2. 拖到目标空格上，该格边框变实线并高亮，松手即完成搬家；
3. 想放弃就按 Esc，或把卡片拖回原处松手。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.2.0.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.2.0**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢失。

## 说明

- 搬家只能落到空格；想和某个格子换位，先把其中一个搬到别处再搬回来即可；
- 安装包暂未做代码签名，首次运行 SmartScreen 可能提示，选择"更多信息 → 仍要运行"。
