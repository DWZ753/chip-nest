# ChipNest v1.6.0 · 库存入口整理与图标优化

## 本次改动

- 新增统一的「库存」入口，手工入库、BOM 整表入库和 BOM 取料流程集中在一起。
- 「仓库布局」专注于货架分区和格子尺寸设置。
- 优化应用图标，并同步更新 Windows、网页和触屏图标。

## 升级

安装前关闭正在运行的 `ChipNest.exe`。数据保存在 `%APPDATA%\ChipNest\`，
此版本没有数据库结构变更。
