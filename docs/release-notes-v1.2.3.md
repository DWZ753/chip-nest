# ChipNest v1.2.3 · 跨格合并与单独挪共用格

修补 v1.2.2 里两处不好用的地方：占用格只有横着能合并、共用格没法单独挪。

## 本版改动

### 跨格合并支持竖着与方块

- 同一物料的占用格只要**能拼成一个完整矩形**就合成一张跨格卡：横着连（1×2）、
  竖着连（2×1）、方块（2×2、3×2…）都行；
- 拼不成矩形的（比如 L 形、隔着一格）仍是一格一张卡：主格出正常卡片，其余出带「共用」标的卡片；
- 每个格子按自己的行列显式摆位，跨格卡不会把后面的格子挤错位。

### 共用格可以单独挪动

- 「移动」模式下直接点那张**带「共用」标的卡**，拿起的是**这一格**，不是主格：
  再点一个空格就把这格挪过去（主格、库存、其它占用格都不动）；
- 顶栏会显示当前拿着什么：「已拿起「××」（1区/1层/0格）」或「拿着共用格 1区/2层/7格」；
- 拿起共用格时点别的有料格子不会误操作；按 Esc 放回原处，点「退出移动」结束；
- 「合并格」模式下点共用卡仍然是**解除**那一格，两个模式各司其职。

### 文案

- 共用卡上的 `1区/1层/5格` 那行坐标去掉了（离得远也找不到，反而碍眼），改成链接图标 + 「共用」小标；
- 设置里的「格子显示」改为 **卡片**，并删掉「同一物料的相邻占用格」那句说明。

## 安装与升级

1. 下载本页附件 `ChipNest-Setup-1.2.3.exe`；
2. **升级前请在任务管理器结束 `ChipNest.exe`**；
3. 运行安装包按向导安装，启动后左上角应显示 **v1.2.3**；
4. 数据保存在 `%APPDATA%\ChipNest\`，覆盖安装不会丢。
